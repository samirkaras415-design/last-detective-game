# المحقق الأخير — النسخة التجريبية الأولى

لعبة ألغاز بوليسية عربية خفيفة تعمل على متصفح الهاتف.

## التشغيل
1. فك ضغط الملف.
2. افتح `index.html` بمتصفح الهاتف أو الكمبيوتر.
3. ابدأ التحقيق واجمع الأدلة الثلاثة ثم اختر المتهم.

## رفعها إلى GitHub
ارفع محتويات هذا المجلد إلى المستودع، مع إبقاء `index.html` في المجلد الرئيسي.
يمكن لاحقًا تفعيل GitHub Pages لتشغيل اللعبة من رابط.

هذه نسخة أولية ثنائية الأبعاد خفيفة وليست تطبيق APK أو لعبة ثلاثية الأبعاد بعد.
